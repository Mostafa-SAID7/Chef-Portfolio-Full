# FullyPorto

A full-stack portfolio application built with Angular and .NET Core API.

## 🚀 Features

- Modern Angular 20 frontend with Server-Side Rendering (SSR)
- .NET Core backend API
- Responsive design
- Fast and optimized performance

## 📋 Prerequisites

Before you begin, ensure you have the following installed:

- [Node.js](https://nodejs.org/) (v18 or higher)
- [Angular CLI](https://angular.io/cli) (v20.3.3)
- [.NET SDK](https://dotnet.microsoft.com/download) (for backend API)
- Git

## 🛠️ Installation

### Frontend (Angular)

1. Navigate to the Angular directory:
   ```bash
   cd Angular
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

4. Open your browser and navigate to `http://localhost:4200/`

### Backend (API)

1. Navigate to the API directory:
   ```bash
   cd MyPortApi
   ```

2. Restore dependencies:
   ```bash
   dotnet restore
   ```

3. Run the API:
   ```bash
   dotnet run
   ```

## 📦 Available Scripts

### Frontend

- `npm start` - Start development server
- `npm run build` - Build for production
- `npm test` - Run unit tests
- `npm run watch` - Build with watch mode
