Favicon Generator for FullyPorto

This tool generates favicon images in multiple sizes. Click the buttons to download.

16×16 (favicon.ico)
32×32 (favicon.ico)
180×180 (Apple Touch)
192×192 (Android)
512×512 (PWA)

Instructions:

  1. Download all the sizes above
  2. For favicon.ico: Combine 16×16 and 32×32 using an online ICO converter
  3. Rename 180×180 to apple-touch-icon.png
  4. Rename 192×192 to icon-192.png
  5. Rename 512×512 to icon-512.png
  6. Place all files in the public folder
